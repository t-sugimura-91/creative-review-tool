# creative-review-tool

SET UPとクライアントが、制作物（画像、動画、文章、LP）を確認し、コメントと承認状態を残すWebツール。

- 公開先（案）: `review.setup-inc.com`
- 要件: setup-marketing リポジトリの `projects/creative-review-tool/requirements.md`（正本）
- 状態: 要件定義ドラフト段階。実装前

## 守ること
- クライアントごとに閲覧範囲を分ける。他社の制作物・コメントは見せない
- パスワード、APIキー、トークンをコードやこのリポジトリに置かない（環境変数で渡す）
- クライアントの個人情報や制作物の実データをコミットしない
- ツール上の「確認OK」は、審査部の審査通過と社長の承認の代わりにならない
